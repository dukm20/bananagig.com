## Architecture

Modular monolith in a pnpm/Turborepo workspace. PostgreSQL (with PostGIS) is authoritative; NATS JetStream carries events; Valkey, OpenSearch and S3 (SeaweedFS) hold derived data and blobs. Everything runs locally under Docker Compose behind Caddy. See `docs/engineering/APPLICATION_ARCHITECTURE.md` and `docs/engineering/CONTAINER_ARCHITECTURE.md`.

## External integrations

None to external services. The verification email is delivered over SMTP to Mailpit locally and in CI; no production email provider is selected (DEBT-0049). The verification SMS goes to a fake sink in Valkey (DEV/TEST only, codes expire after 15 minutes) and the production transport is `disabled`: sends fail closed until a provider is chosen (DEBT-0059); line-type and risk lookups use a fake classifier locally and `unknown` in production (DEBT-0060). Local-only stand-ins: Mailpit (SMTP sink), Keycloak realm `bananagig` with dev-only users (`customer.dev`, `provider.dev`, `admin.dev`, `admin2.dev`), flagd (one flag). Keycloak sends its password-reset email through Mailpit locally; the production realm build removes that SMTP server, so production needs its own (DEBT-0016). BananaGig calls the Keycloak admin API with the service account client `bananagig-security` (role `manage-users`, client credentials only; DEBT-0071).
